1. Select Topics

Choose the academic areas you care about - we use them to recommend sources.

How topics are used

Topics drive two things: which databases get recommended below, and the coverage map after a fetch (are you missing sources people often expect for this topic?). Your collection stays private to this account.

Quick packs for common topics

One click sets topics and checks common free sources for that area. You can still adjust checkboxes.

2. Choose Sources

Select topics above to see recommended sources, or choose manually below.

About the sources

Each source is a free public academic database (not a college library package). Every checkbox has a Student tip (what it is good for and what it misses). NASA ADS needs a free server token — without it that source simply skips. bioRxiv / medRxiv are preprints (not peer-reviewed; recent window only). DBLP is strong on CS titles/venues but many records have no real abstract (those are skipped). Topics + coverage map use the same recommended source lists so they stay aligned.

3. Fetch Articles

2. Fetch Articles

Searches every selected source at once, saves the papers to your private collection, then automatically prepares them for search (you can leave this page open while progress runs).

How fetching works

The query runs against every selected source in parallel as a background job (progress bar; Cancel stops after the current source). Saves title, abstract, authors, year, and journal. Records without an abstract are skipped (later steps need text). When at least one paper is saved, prepare-for-search starts next as another background job (same progress area). Some sources may fail (rate limits, API rules) while others succeed — that is normal; check the per-source list. Your last query, sources, and email are remembered in this browser.

What preparing does (embeddings)

Preparing creates embeddings: each abstract becomes a numerical "meaning fingerprint" that powers Search (hybrid ranking, seed, and more-like-starred), Clusters, and Duplicate detection. It runs as a background job with a progress bar (you can leave the page open) and uses your GPU when available. The model is chosen from your topics (biomedical → pubmedbert, hard science → specter, otherwise general) unless you pick one under Advanced. Only prepare new papers turns on for Add to collection and off for Replace. Switching models reprocesses everything so dimensions stay consistent.
