Email for account recovery (optional)

You sign in with your username. Adding an email is optional and does one thing: if you forget your password, we can send a reset code to that address.

Why verify, and what we do with it

An address only counts once you click the link we send — anyone can type any address, so clicking is what proves it is yours. Until then it does nothing. We use it for password recovery only: no newsletters, no sharing. You can remove it at any time, and removing it just means you would need the person running this server to help if you ever get locked out.

Email sending is not set up on this server, so an address cannot be verified and this is switched off. Whoever runs the server can enable it by setting SMTP_HOST and the related settings (see .env.example). Password reset still works — it shows a one-time code on screen instead.
Your login looks like an email address. Verify to turn on password recovery — your username does not change.

Change password

Updates your password and signs out other sessions immediately (this browser stays signed in with a fresh session). New password: at least 8 characters (max 72 bytes for secure hashing). You can change it again anytime from this page.

Delete Account

This permanently deletes your account and everything in your workspace - all fetched articles, embeddings, clusters, screening choices, stars, and notes. Export CSV / RIS / BibTeX from Search first if you need a hand-in archive. This cannot be undone.
